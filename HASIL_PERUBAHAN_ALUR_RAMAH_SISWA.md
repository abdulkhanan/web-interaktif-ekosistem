# Revisi Alur Guided Inquiry agar Lebih Ramah Siswa

Perubahan utama:

1. Istilah sintaks dibuat lebih sederhana menjadi: **Amati → Tanya → Duga → Coba → Catat → Cocokkan → Simpulkan**.
2. Halaman simulasi diberi **Lembar Bantu Sebelum Menjalankan Simulasi** agar siswa tahu:
   - variabel apa yang diubah,
   - hasil apa yang diamati,
   - pola rumusan masalah,
   - pola hipotesis/dugaan,
   - data apa yang perlu dicatat.
3. Halaman Tanggapan Siswa diberi placeholder/kalimat bantu pada setiap kolom jawaban.
4. Bahasa pertanyaan dibuat lebih mudah dipahami siswa, tetapi tetap sesuai sintaks guided inquiry.
5. Tombol simulasi diubah menjadi **Pilih Hasil Ini untuk Menjawab** agar siswa paham fungsi tombol.

Catatan: struktur database tidak diubah. Kolom lama tetap dipakai agar aman dengan Supabase yang sudah ada.
