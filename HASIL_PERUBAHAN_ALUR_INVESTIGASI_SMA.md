# Hasil Perubahan Alur Investigasi Level SMA

Versi ini merevisi alur agar guided inquiry tidak tampil sebagai daftar sintaks yang kaku di depan siswa. Sintaks tetap digunakan sebagai struktur pembelajaran, tetapi pengalaman siswa dibuat menjadi investigasi ilmiah.

## Alur baru

1. Kasus
2. Rencana Investigasi
3. Simulasi dan Data
4. Klaim Ilmiah

## Perubahan utama

- Halaman simulasi berubah menjadi **Investigasi Ekosistem**.
- Label teoritis seperti “Orientasi/Rumusan Masalah/Hipotesis” tidak ditampilkan terlalu dominan pada halaman simulasi.
- Siswa diarahkan membaca kasus, menentukan fokus, mengatur variabel, membaca pola data, lalu menyusun klaim ilmiah.
- Halaman tanggapan berubah menjadi **Klaim Ilmiah Siswa**.
- Struktur jawaban menggunakan alur: rumusan masalah, dugaan awal, pola data, klaim-bukti-alasan-implikasi.
- Tidak ada contoh jawaban jadi, sehingga lebih sesuai untuk tingkat SMA.
- Struktur database tetap sama agar aman dengan Supabase lama.
