CARA PASANG TAHAP 3

1. Pastikan Tahap 2 sudah normal.
2. Backup repository sebelum menimpa file.
3. Ekstrak patch Tahap 3.
4. Copy semua isi folder patch ke folder utama repository lokal.
5. Saat Windows bertanya Replace or Skip Files, pilih Replace All.
6. Jangan menghapus folder .git.
7. Tidak perlu menjalankan SQL baru.
8. Buka GitHub Desktop.
9. Pastikan file baru dan perubahan terdeteksi.
10. Commit dengan nama: Tahap 3 - Misi 1 Guided Inquiry Lengkap
11. Push origin.
12. Tunggu Streamlit redeploy.
